# Your Screen Holds a Secret

## Overview
An interactive personal website built using HTML, CSS, and vanilla JavaScript. Visitors reveal a sequence of messages by clicking the screen, accompanied by animated fireworks-style particle effects.

## Features
- Progressive message reveals triggered by user clicks
- JavaScript DOM manipulation and event handling
- Click-triggered particle effects with randomised movement
- CSS animations, gradients, and custom visual styling
- Centred webpage layout using CSS Flexbox
- Custom typography using Google Fonts

## Technologies Used
- HTML5 — webpage structure and content
- CSS3 — layouts, styling, and animations
- JavaScript — interactive messages and particle generation

## Project Structure

- `index.html` — main webpage structure
- `styles.css` — styling and animations
- `script.js` — JavaScript interactions and particle effects
- `README.md` — project documentation

## Getting Started
1. Download or clone this repository.
2. Open `index.html` in a web browser.
3. Click anywhere on the page to reveal messages and trigger particle effects.

## Project Background
A personal front-end development project exploring interactive storytelling, JavaScript event handling, DOM manipulation, and CSS animations.
